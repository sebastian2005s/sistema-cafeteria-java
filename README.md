# Sistema de Gestión de Pedidos - Cafetería

Sistema básico en Java para la gestión de pedidos de clientes en una cafetería universitaria.
Incluye encapsulamiento, manejo de estados, listas (ArrayList) y validaciones de negocio.

## Clases
1. `EstadoPedido`: Enum (PENDIENTE, ATENDIDO, CANCELADO).
2. `Pedido`: Gestiona los detalles y calcula el subtotal.
3. `Cliente`: Almacena información y la lista de pedidos con validaciones de unicidad.
4. `Main`: Demuestra el funcionamiento general.
